# hao-backprop-test

A minimal Node.js HTTP server built with the [Express](https://expressjs.com/) framework. It exposes two plain-text endpoints and serves as a small tutorial project.

> **Note:** This repository began as a backprop integration test project and has since been extended into a minimal Express tutorial; it is now actively maintained.

## Prerequisites

- **Node.js `>= 18`** — required by Express 5 (its `engines.node` is `">= 18"`).
- **npm** — bundled with Node.js.

The project now has a dependency tree, so you must install dependencies before running it. They are installed into `node_modules/`, which is generated by `npm install` and is git-ignored.

## Getting Started

```bash
# 1. Install dependencies (Express, Jest, Supertest)
npm install

# 2. Start the server
npm start
```

`npm start` runs `node server.js`, which listens on <http://127.0.0.1:3000/> and logs:

```text
Server running at http://127.0.0.1:3000/
```

## Endpoints

The server binds to host `127.0.0.1` on port `3000` and exposes the following routes:

| Method | Path            | Status | Content-Type | Response body     |
|--------|-----------------|--------|--------------|-------------------|
| `GET`  | `/`             | `200`  | `text/plain` | `Hello, World!\n` |
| `GET`  | `/good-evening` | `200`  | `text/plain` | `Good evening\n`  |

Both response bodies include a trailing newline (`\n`). The `GET /` route preserves the project's original greeting, while `GET /good-evening` is the newly added endpoint.

Any other path or HTTP method returns Express's default **`404 Not Found`** response. Explicit Express routing replaces the original catch-all handler, which previously answered every request with the same body.

## Example Requests

```bash
# GET /  ->  "Hello, World!"
curl http://127.0.0.1:3000/

# GET /good-evening  ->  "Good evening"
curl http://127.0.0.1:3000/good-evening
```
